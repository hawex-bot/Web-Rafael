BAB I
PENDAHULUAN

1.1 Latar Belakang

Komputer merupakan alat elektronik yang banyak digunakan dalam kehidupan sehari-hari. Dalam penggunaannya, komputer membutuhkan proses untuk menerima data dan menghasilkan informasi. Proses tersebut berkaitan dengan input dan output.

Input dan output merupakan bagian penting dalam sistem komputer. Keduanya membantu pengguna berkomunikasi dengan komputer sehingga pekerjaan dapat dilakukan dengan lebih mudah.

1.2 Rumusan Masalah

  • Apa pengertian input dan output?
  • Apa saja contoh perangkat input dan output?
  • Apa fungsi perangkat input dan output?

1.3 Tujuan

  • Mengetahui pengertian input dan output.
  • Memahami jenis perangkat input dan output.
  • Mengetahui fungsi masing-masing perangkat.

BAB II
PEMBAHASAN

2.1 Pengertian Input dan Output

Input adalah proses memasukkan data atau perintah ke dalam komputer agar dapat diproses. Sedangkan output adalah hasil dari pengolahan data yang dikeluarkan oleh komputer kepada pengguna.

2.2 Perangkat Input

Perangkat input adalah perangkat keras yang digunakan untuk memasukkan data atau perintah ke komputer. Beberapa contohnya yaitu:

  • Keyboard: digunakan untuk memasukkan huruf, angka, dan simbol.
  • Mouse: digunakan untuk menggerakkan kursor dan memilih menu.
  • Scanner: digunakan untuk memindai dokumen atau gambar.
  • Microphone: digunakan untuk memasukkan suara ke komputer.
  • Webcam: digunakan untuk mengambil gambar atau video.

2.3 Perangkat Output

Perangkat output adalah perangkat keras yang berfungsi menampilkan hasil pengolahan data dari komputer. Contohnya yaitu:

  • Monitor: menampilkan informasi dalam bentuk gambar dan tulisan.
  • Printer: mencetak dokumen atau gambar ke kertas.
  • Speaker: menghasilkan suara dari komputer.
  • Projector: menampilkan gambar komputer ke layar yang lebih besar.

2.4 Contoh Penggunaan Input dan Output

Contoh penggunaan input dan output dapat ditemukan saat seseorang mengetik tugas menggunakan komputer. Pengguna memasukkan tulisan melalui keyboard sebagai input, kemudian hasil tulisan ditampilkan pada monitor sebagai output.

Contoh lainnya adalah ketika seseorang mencetak dokumen. Data dimasukkan melalui komputer, kemudian printer menghasilkan dokumen dalam bentuk cetakan.

2.5 Perbedaan Input dan Output

Perbedaan utama input dan output terletak pada fungsinya. Input digunakan untuk memasukkan data ke komputer, sedangkan output digunakan untuk menampilkan hasil pengolahan data.

BAB III
PENUTUP

3.1 Kesimpulan

Input dan output merupakan bagian penting dalam sistem komputer. Input berfungsi memasukkan data atau perintah, sedangkan output berfungsi menampilkan hasil pengolahan data. Keduanya saling berhubungan agar komputer dapat bekerja dengan baik.

3.2 Saran

Pengguna komputer sebaiknya memahami fungsi perangkat input dan output agar dapat menggunakan komputer dengan benar dan sesuai kebutuhan.
